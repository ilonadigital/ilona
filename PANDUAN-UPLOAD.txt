UPLOAD KE REPO ilonadigital/ilona
1. Ekstrak ilona-website-upload.zip di komputer.
2. Di halaman utama repo, buka Add file > Upload files.
3. Dari Finder / File Explorer, seret index.html, studio.css, studio.js, dan folder assets ke kotak upload GitHub.
4. Tunggu semua file selesai diunggah, lalu klik Commit changes.
5. Gunakan pengaturan GitHub Pages atau deployment yang sudah ada untuk repo tersebut.
6. Setelah deployment selesai, buka halaman website dan refresh.

Pastikan index.html sejajar dengan studio.css, studio.js, dan folder assets di halaman utama repo.
Folder assets beserta isinya perlu ikut diunggah, karena ada screenshot Akela tambahan dan aset mockup iPhone.
File menggunakan jalur relatif sehingga bisa digunakan di root domain maupun subfolder /ilona/.

Paket ini adalah website statis dan tidak memerlukan proses build tambahan.
Formulir konsultasi tetap memakai Google Forms Ilona yang sudah ada.
