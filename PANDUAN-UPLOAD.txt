UPLOAD KE GITHUB
1. Ekstrak ZIP ini di komputer.
2. Buka repo ilonadigital/ilona pada branch yang dipakai website.
3. Di halaman utama repo, pilih Add file > Upload files.
4. Seret index.html, studio.css, studio.js, dan folder assets dari hasil ekstrak.
5. Commit changes.

index.html harus langsung berada di root repo, bukan di dalam folder tambahan.
Upload file hasil ekstrak, bukan file ZIP. Jika browser tidak menerima folder, buka folder assets di repo lalu upload file ke subfolder yang sama.
Tiga aset baru ada di assets/brief/: gonegani-gmv-january.png, gonegani-gmv-february.png, zerox-shopee-ads.png.

Paket dapat dipakai di root domain maupun subfolder karena menggunakan path relatif.
Pertahankan pengaturan domain, CNAME, dan GitHub Pages yang sudah digunakan.
